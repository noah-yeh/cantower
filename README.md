# 残塔 · Ruin Spire

竖屏、单手。在大厅花金币招募「种族 × 职业」的角色，派他去爬 30 层魔塔。
**活着回来才算数**：死了扣一条命、这一趟的成果全部清零。归来的角色可以拿去
竞技场打异步 PvP 赚金币，命扣光角色永久消失。

对标 TapTap《了不起魔塔》的骨架。v0.4 起把局外从"选角色"扩成完整大厅循环，v0.5 加入升级系统，
v0.6 对齐原作属性面板（8 项：生命/攻击/防御/暴击/闪避/知识/幸运/恢复），
v0.7 招募改计时制（6 席位 + 冷却），v0.8 新招角色需探险归来转正才能进竞技场，v3.5 招募改名额制（一次一位，名额上限 10、每 10 分钟 +1），
v0.9 加广告位占位（看完 +30 金，每日 5 次，播放器可替换成真实 SDK），
v1.0 敌人改成和玩家同构：抽牌 + 真实能量，取消意图预告，改看战斗记录；
v1.1 转正即封塔（塔只爬一次），竞技场额度改为计时恢复，删掉按探险次数递增的难度。

## 玩

```bash
npm run serve        # http://127.0.0.1:4182/
```

**大厅**

- 大厅一屏放下：原画主视觉 + 两个主动作（冒险 / 竞技场）+ 小图标行（营地 / 图鉴 / 庄园 / 墓地 / 广告）+ 招募；规则收在右上角「?」，全部数值可查「图鉴」
- 招募一次出一位：点「招募」耗 1 个名额（上限 10，每 10 分钟 +1）抽出候选人，
  **雇佣 100 金**或婉拒（免费、名额不退），处理完才能点下一次；20 金可换一位（不吃名额）。
  候选上能直接看到种族、职业、命数、掷出的生命/攻击/面板属性/每级成长
- 营地（名册）最多 6 人，大厅点「营地」进入，实习/转正分 tab。点「出发探险」开一局，「背包」看卡组与宝物，「竞技场」赚金币
- **一次只能有一个人在塔里**：有人探险时，冒险页其他实习生的「出发」置灰为「等待中」，
  逻辑层 `canExplore` 也会拦下（防止新开局覆盖在跑的存档）
- **新招的人是试用期**：只能探险，活着从塔里回来一次才转正，转正后才解锁竞技场（见下）
- 命数用红点表示。探险阵亡扣 1 条命，命扣光进墓地

**探险（20–30 分钟）**

- 点手牌出牌，「结束回合」让敌人行动。敌人和玩家**同一套回合结构**：抽牌 → 回满能量 → 买得起就打，
  买不起就结束回合。它**不再预告意图**，但顶栏「记录」能看到双方每一次出牌的**实际结果**
  （`打击 · -7（护甲吃 5）`、`能量不足，结束回合`）
- **随时可暂停回大厅**：地图页与战斗页顶栏都有「⏸」（页面底部也有「暂停 · 回大厅」条），
  不扣命、进度保留，大厅点角色上的「继续探险」原样回塔
- 每打赢一层先结算经验（可能升级），再三选一：卡牌 / 宝物 / 治疗
- **升级只加本职业那一项**：战士 +7 最大生命 / 法师 +3 知识 / 猎人 +1 攻击 / 旅行家 +5 幸运。
  知识 = 印记（中毒/虚弱）叠加层数 +1%/点，对齐原作截图的定义，不碰护甲/治疗/攻击
- **面板属性**：招募时按职业掷定 防御/暴击/闪避/恢复（基础值 ±1）。防御减伤 1%/点（封顶 40），
  暴击 +1% 率（1.5 倍伤害，封顶 50），闪避 +1% 免伤（封顶 30），恢复战胜后回 1 血/点。
  敌人只有精英（防御 2）和首领（防御 4）带面板
- 顶栏「背包」可以：两张同名卡合成强化版（+50%，上限 3 次，产出 1 个材料）、花 3 材料激活种族宝物
- 第 5、15、25 层精英，第 10、20、30 层首领

**归来与阵亡**

| 事件 | 命数 | 成果 |
|---|---|---|
| 活着通关 | 不变 | 卡组、宝物、等级与属性全部保留 + 金币；**首次归来即转正** |
| 探险阵亡 | −1 | **全部回滚到招募时**，0 金币；仍在试用期的还是试用期 |
| 竞技场失败 | −1 | 不回滚（竞技场只赌命，不赌成长） |

**转正：塔只爬一次（v0.8 立规，v1.1 补齐反向约束）**

招募来的角色 `veteran=false`，只能探险；活着回来一次变 `true`，同时拿到 3 次竞技场额度。
**转正之后塔就关上了** —— 这个角色剩下的路只有竞技场。阵亡不会取消已获得的转正身份。

判定收敛在两个函数上，都能被 `node --test` 直接验证：

- `roster.canExplore(ch)` —— 已转正 / 没有命 → 进不去塔
- `roster.canEnterArena(ch, now)` —— 未转正 / 额度 0 / 没有命 → 进不去竞技场

**竞技场额度按时间恢复**：上限 3 次，每 30 分钟 +1（满额时不走表）。转正后不能再进塔，
所以额度不能靠"探险归来重置"，只能走计时。

中途退出按阵亡算 —— 否则可以在快死时退出重来。

## 四条硬规则

1. **血量跨层延续** —— 一场打完剩多少血，原样带进下一层。一次探险只有一条命
2. **能量固定** —— 每回合 10 点，不随层数增长
3. **护甲战斗内保留、战斗结束清零** —— 叠甲流成立的前提
4. **角色是消耗品** —— 成长只在活着回来时保留，失败全清。这是整套经济的心脏

  enemyTraits.js 核心词条 / 变异词条 / 威胁值
  enemies.js     模板 + 牌库组装 + 层数曲线 + 出牌计划（调参只改这里）

  leveling.js    升级 + 属性面板：经验曲线 / 四职业成长表 / 知识=印记倍率 / 属性上限（调成长只改这里）
  run.js         一次探险：层推进 / 三选一 / 经验结算 / 合成 / 宝物激活

## 命令

```bash
npm test                      # 89 项规则测试
node tools/balance.mjs 20     # 20 局 × 16 组合 = 320 局单局模拟
node tools/meta-sim.mjs 80    # 连续 80 次"探险 + 竞技场 + 招募"（第 2 参数可传种子，调元游戏必须多种子）
node tools/trace.mjs warrior stone 7
```

**两套模拟分工**：`balance` 只看单局通关率与职业差距，`meta-sim` 看长期经济
（金币会不会破产/溢出、角色平均活几次）。只跑前者会得出"合成太强"这类局部结论。

## 角色的组成

| 层 | 提供什么 |
|---|---|
| 种族 | **命数**（石头人 7 / 青苔族 6 / 影族 5 / 余烬族 3）、被动、**2 件未激活宝物**、1 张种族卡 |
| 职业 | 基础生命/攻击、职业天赋、12 张职业牌库 |
| 掷骰 | 生命与攻击在 ±8% 内浮动，同一个组合招两次数值不同 |
| 卡组 | 5 张保底 + 随机 4 张职业牌 + 1 张种族卡 = 10 张 |

起始池**排除 power 牌**（奥术强化/战吼/瞄准/植物精华）——这些是永久成长牌，
随机白送一张等于 +30%~40% 攻击，会把法师和猎人的通关率顶到 75% 以上。

## 敌人的构筑

| 层 | 数量 | 作用 |
|---|---|---|
| 模板 | 10 普通 + 3 首领 | 基础系数 + 6~8 张行动牌 |
| 核心词条 | 1 个，固定 | 身份：骸兵复活、石像鬼开场带甲、织网蛛抽你能量 |
| 变异词条 | 普通 1 / 精英 2 / 首领 2 | 这一局的变化。同样的骸兵，这局带再生，下局带尖刺 |

敌人和玩家走同一套出牌流程：每回合抽 4 张、回满 5 点能量，买得起就打、买不起就结束回合
（每回合最多 2 张）。**它不预告意图**——顶部「记录」按钮能翻本场战斗的回放，
逐条看双方打出的牌和实际结果。变异词条带威胁值，强的词条会从基础 HP/ATK 里扣回来，
**变异只改打法，不改难度**。

竞技场是例外：对手用**玩家规格**（10 能量 / 抽 5 / 打 4 张），攻击力 ×4.3 补偿，
否则 5 能量 2 张的敌方会形成 2 倍 DPS 差，玩家必赢。

## 数值现状（2026-11-04 实测）

**单局（320 局，v1.0）**

| 职业 | 通关率 | 中位层数 | 中位时长 | 每场回合 |
|---|---|---|---|---|
| 战士 | 44% | 29 | 23.1 分 | 3.1 |
| 法师 | 39% | 29 | 16.2 分 | 1.7 |
| 猎人 | 57% | 31 | 16.9 分 | 1.8 |
| 旅行家 | 54% | 31 | 19.9 分 | 2.4 |

总通关率 **48%**，职业差距 1.46×。敌人能量从 3 涨到 5、抽牌 3→4 后 DPS 上升，
已用 `atkBase` 5.5→4.8 抵掉一部分（55%→48%）。法师偏低，下轮再调。

**元游戏（120 次行动 × 3 种子，v1.1）**：探险通关率 **48.6% / 38.6% / 53.1%**（均值 46.8%），
每角色平均探险 2.1 次（先失败一次，再爬一次转正），结束金币 318~780，无溢出。
竞技场胜率 43.8% 偏低（目标 50–55%），是下一轮的杠杆。

> v1.0 时这里是 16% —— 差距来自 `diffMul`。那条曲线按"角色探险次数"给敌人加属性，
> 但转正封塔之后一个角色只会进塔一次，它剩下的唯一效果就是惩罚失败者。
> 删掉后回到 46.8%。

**现在的负反馈只有一条半**：

| 机制 | 做法 |
|---|---|
| 塔只爬一次 | 转正即封塔，成长不可刷 —— 从源头堵住"强者恒强" |
| 对手会变强 | 竞技场幽灵按玩家评级动态缩放（评级含等级/知识/幸运） |

v0.4 曾有三条：「成长天花板」（v0.5 取消，固定值升级天然有上限）、
「塔认得你」（v1.1 取消，转正封塔后失去对象）。
**难度现在只由层数决定**：同层敌人属性恒定，跟角色经历过什么无关。

硬性约定：**平衡结论只认模拟，不凭手感**。

## 已知问题

- 每场战斗仍只有 1.5–3 回合。根因是"30 层纯战斗 + 没有续航"，需要补商店/休整点（恢复属性是第一个补丁）
- 平衡整体未校准（v0.7 故意没动）：竞技场均值 64%、个别种子探险 68% 通关，下轮统一调
- 竞技场对手是折算强度，不是 1:1 还原玩家卡组；要给幽灵发面板才能真对抗
- 单局时长 18.5 分钟，低于 20–35 的目标（估算是"回合数 × 11 秒"，真人会更慢）
- 浏览器实机还没跑通完整一局（本机 Edge 无头模式不可用），UI 是 Node 桩 + 渲染字符串验证的
